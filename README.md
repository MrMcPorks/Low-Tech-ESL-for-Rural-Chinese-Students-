# Low-Tech ESL for Rural Chinese Students

A personal project exploring how to make beginner English vocabulary practice accessible with minimal technology. I’m building this independently because I want to do something meaningful with my time and create something that could eventually be useful to learners with limited resources.

**Last updated:** 2026-09-19  
**Current phase:** Planning — Vocabulary Trainer  
**Scope:** Independent development; no classroom implementation or learner testing is currently scheduled.

## Phase 1: Vocabulary Trainer

The trainer will be designed to support three sets of 1,000 conversational English words, organized by increasing difficulty. The initial goal is to complete the first set. The remaining sets will allow the program to expand for more advanced learners.

1. **Beginner vocabulary:** Complete the first set of 1,000 foundational words.
2. **Adaptive practice:** Build flashcard-style exercises that adjust based on the learner’s performance.
3. **Checkpoint quizzes:** Include quizzes after defined groups of words to reinforce learning.
4. **Interface development:** Use the vocabulary trainer to develop and refine the program’s overall interface.
